# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/). Data corrections are patch releases and
must cite their source.

## [Unreleased]

### Changed
- LGA names cross-checked against INEC's voter registration portal (cvr.inecnigeria.org,
  October 2026). Seven names corrected: Girei, Guyuk, Dambam, Birniwa, Aliero, Yakurr and

  Birniwa/Birnin Kudu (Jigawa) swapped to keep v1 codes alphabetical.
- INEC's variant spellings added as aliases for 23 LGAs.
